# Python Voice Assistant 🎙️🤖

A simple voice assistant built using Python.

## Features

- Voice input
- Text-to-speech
- Open Google
- Open YouTube
- Google search
- Tell current time
- Tell current date
- Play music
- Open Calculator
- Open Notepad

## Technologies Used

- Python
- SpeechRecognition
- SoundDevice
- SoundFile
- Pyttsx3

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
pip install sounddevice
pip install soundfile
pip install SpeechRecognition 
pip install pyttsx3
